# 会议纪要规范

## 一、讨论 / 决议 / 待办 的判定

**讨论要点**（可省略）
- 特征：有人提出、有人回应，但没有落到「就这么办」。
- 保留标准：影响后续判断的观点、关键数据、关键分歧。
- 写法：「张某某提出……，理由是……」。

**决议**（必须有）
- 特征：出现「就这么定」「按这个来」「下周开始」这类拍板信号，且主持人或有权的人认可。
- 写法：「确定 ……」。要能回答三个问题：定了什么、为什么、什么时候生效。
- 反例：「大家倾向于 A 方案」→ 这是讨论，不是决议，除非明确说「就按 A 做」。

**待办**（必须有）
- 四要素：做什么、谁做、什么时候交、交给谁或交成什么样。
- 只有「做什么」没有责任人 → 记为「待指派」，不要默认塞给发起人。
- 只有「尽快」没有日期 → 记为「待定」，并在待确认事项里提醒会上补时间。

## 二、六类常见整理错误

1. **把讨论拔高成决议**：会上只是倾向，纪要却写成定了。后果是执行时有人反悔，纪要失去可信度。
2. **待办无主**：写了「需要跟进一下」但没人名，最后没人做。
3. **纪要被写成逐字稿**：按发言顺序罗列，读的人找不到重点。正确做法是按议题重排。
4. **丢掉反对意见与前提条件**：决议的前提条件（预算批下来、法务确认）没写，执行时才发现卡住。
5. **数字口语化**：会上说「差不多两百万」，纪要照抄。应写成「约 200 万元（口径：含税，待财务确认）」。
6. **时间不够具体**：「下周三前」在跨周会议里会歧义，写成绝对日期。

## 三、口语转书面语的常见对照

| 会上原话 | 纪要写法 |
| --- | --- |
| 这个事我们下周再聊 | 该事项延至下周会议继续讨论，需先补充…… |
| 差不多就这么定了 | 确定按 A 方案推进（前提：……） |
| 你们回去弄一下 | 待办：×× 于 ×月×日 前提交……，抄送 ×× |
| 预算应该够 | 预算充足性待财务确认（初步口径：约 ×× 万元） |

## 四、整理时的自查问句

1. 没参会的人照着这份纪要，能不能直接开工？
2. 每条待办的责任人，看到自己名字时会不会觉得意外？（意外说明会上没确认过）
3. 有没有哪条写成了「既像决议又像建议」？
4. 会上的关键数字、金额、日期，是否都写上了口径与来源？
