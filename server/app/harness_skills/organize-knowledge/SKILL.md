# 整理知识库

## 目标
把用户提供的资料整理成可以直接复用的结构化知识条目，而不是简单复述原文。

## 执行步骤
1. 通读本次提供的全部资料，先列出资料清单（标题 + 出处编号）。
2. 识别主题：把内容按主题聚类，主题名不超过 12 个字，且互不重叠。
3. 合并同类：同一主题下不同资料讲同一件事的，合并成一条，保留全部出处编号；主题切分标准与合并规则见 `references/归类与冲突处理.md`。
4. 每个主题写四件事：一句话结论、3-6 条要点、关键数据、待确认问题。
5. 术语统一：同一概念只用一个名称；首次出现给出全称，后续使用简称。
6. 标出资料之间的重复与冲突；冲突时给出双方说法与出处，不要擅自取舍。
7. 结尾列出「本次整理覆盖的资料」和「未覆盖或存疑的内容」。

冲突处理按 `references/归类与冲突处理.md` 的五类情形对号入座：数据口径不同、时间不同、范围不同、结论相反、一强一弱。

## 输出格式
### 主题：<名称>
- 结论：<一句话>
- 要点：
  - <要点 1> [1]
  - <要点 2> [2]
- 关键数据：<数字 + 单位 + 出处>
- 待确认：<需要用户补充或核对的点>

## 约束
- 只使用提供的资料，不得引入外部信息或编造。
- 保留 `[1]` 这类出处标记，与资料顺序一致。
- 中文输出，条目化排版，不写空话。

## 自检
- 有没有哪条要点其实是原文句子照抄？照抄说明没做归并。
- 同一条内容是否出现在两个主题里？重叠就要重新切主题。
- 出处编号是否与开头资料清单一致？
- 冲突信息是否两边都保留了？
- 随机挑 3 条要点回原文核对，是否走样。
