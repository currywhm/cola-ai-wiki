# 调研框架与信源分级

## 一、六块框架的填写要求

**1. 市场规模与增速**
- 必填：规模数字 + 年份 + 币种 + 口径（出货量／营收／GMV）。
- 至少给两个来源；只找到一个时，在结论里标注「单一来源，待验证」。

**2. 产业链与关键环节**
- 上游／中游／下游各写一句「谁掌握定价权」。
- 找出卡脖子环节（产能、牌照、渠道、技术专利）。

**3. 主要玩家与打法**
- 每个玩家写：定位、核心产品、获客方式、差异点。
- 有份额数据就写份额，没有就写「未见公开份额数据」。

**4. 商业模式与盈利点**
- 写清钱从哪来（一次性／订阅／抽傭／广告／补贴）。
- 单客经济：客单价、获客成本、复购，能查到就写，查不到就写「未披露」。

**5. 政策与监管**
- 列出直接相关的法规、准入要求、资质门槛与最新修订时间。

**6. 风险与不确定性**
- 分三类：需求风险（市场没起来）、供给风险（成本／产能）、政策风险（合规变化）。

## 二、信源分级（每条信息都要打个等级）

| 等级 | 来源类型 | 用法 |
| --- | --- | --- |
| A 一手 | 官方统计、监管文件、上市公司年报／招股书、企业自己发布的财报 | 可直接引用 |
| B 权威二手 | 主流财经媒体、行业协会报告、头部咨询机构 | 可引用，注明机构与年份 |
| C 普通二手 | 一般行业媒体、转载文章、招聘／招投标信息 | 当线索，需交叉验证 |
| D 不可依据 | 自媒体、营销号、无日期无出处的数据、AI 生成内容 | 只能当搜索词灵感 |

## 三、常见数据口径陷阱

1. 把「出货量」与「销售额」混用。
2. 把某个细分市场的规模当成整个行业规模。
3. 把全球数字当中国数字（或反过来）。
4. 拿不同年份的数字直接比增速。
5. 引用咨询机构预测值，却写成已发生的事实（预测值必须标「预测」）。
6. 用「预计 2030 年」这类远期数字支撑当下决策。

## 四、检索技巧

- 官方数据用「统计公报 / 年鉴 / 部门预算 / 白皮书 + 年份」。
- 公司信息用「年报 / 招股说明书 / 投资者关系」。
- 英文补充用「market size / market share / report + year」。
- 检索冲突信息时，加「质疑 / 争议 / 辟谣」等词反向查一遍。
