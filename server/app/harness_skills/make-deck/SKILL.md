# 生成 PPT

## 目标
输出一份可以直接照做幻灯片的分页大纲，控制在 8-15 页。

## 执行步骤
1. 定主线：一句话说清这份 PPT 要让听众记住什么。
2. 定叙事骨架：按 `references/汇报叙事与分页规则.md` 选叙事模式（结论先行 / 问题-方案 / 时间线 / 对比），再按模式拆页。
2. 拆页面：封面、结论页、2-3 个论证页、数据页、结论与行动页。
3. 每页只讲一个观点，标题写成结论句而不是名词堆砌。
4. 每页给 3-5 条要点，每条不超过 20 字，标出处编号。
5. 给每页写一句讲稿提示，说明这一页要说服听众什么。

## 输出格式
### P1 · 封面
- 标题：<主标题>
- 副标题：<补充说明>
- 讲稿提示：<开场怎么说>

### P2 · <结论句标题>
- 要点：
  - <要点> [1]
- 建议版式：<结构/图表类型>
- 讲稿提示：<这一页的落点>

## 约束
- 每页一个观点，标题必须是结论句。
- 数据页必须标明数值与出处；没有数据就换用结构图。
- 中文输出，不写「此处可插入图片」这类占位废话。

## 自检
- 把每页标题连起来读一遍，是否是一条完整的论证链？
- 每页是否只有一个观点，没有把两件事塞在一页？
- 要点是否都在 20 字以内、能直接上屏？
- 数据页是否都有数值与出处？

## 附带文件
- `references/汇报叙事与分页规则.md`：四种叙事模式、每页要素、版式选择、常见毛病。第 2 步用。
- `assets/分页大纲模板.md`：输出骨架，逐页填写。
