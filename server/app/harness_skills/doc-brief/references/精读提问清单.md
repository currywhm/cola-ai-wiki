# 精读提问清单

用法：第 3-5 步时逐组过一遍。能答上来的问题就不用写进笔记，答不上来的才是重点。

## 一、主旨与结构（第 1-2 步）
1. 作者最想让读者记住的一件事是什么？
2. 如果把标题和结论互换，文章还成立吗？
3. 哪一段是全文的枢纽？删掉它文章还成立吗？
4. 文章的开头和结尾是否指向同一个结论？
5. 有没有哪一部分其实可以删掉而不影响结论？

## 二、论断与证据（第 3 步）
6. 哪些是事实陈述，哪些是价值判断？
7. 数据是谁统计的、什么时候统计的、样本多大？
8. 用的是绝对值、比例还是排名？（比例最能骗人，注意分母）
9. 案例是典型样本还是极端样本？
10. 有没有把「相关」说成「因果」？
11. 有没有漏掉反方证据？
12. 论证是归纳（案例→结论）还是演绎（原则→结论）？各自的弱点在哪？

## 三、隐含假设与边界（第 4-5 步）
13. 结论成立需要哪些先决条件？这些条件现在满足吗？
14. 换一个时间窗口，结论还成立吗？
15. 换一个地区、行业、规模，结论还成立吗？
16. 有没有「幸存者」被排除在样本外？
17. 如果作者立场相反，他会怎么反驳这篇文章？
18. 文中出现「显然」「众所周知」「毫无疑问」的地方，是不是恰恰没论证的地方？

## 四、可信度与可用性（第 6-8 步）
19. 作者的立场与利益关系是什么（卖服务？推产品？为政策辩护？）？
20. 文中哪些结论可以直接用，哪些必须先核实？
21. 如果要照着做，第一步应该做什么、需要什么资源？
22. 这份资料在哪里会过时？多久要重新看？
23. 有没有互相对立的其它资料？冲突点在哪？
24. 如果只能向作者问一个问题，问什么最有价值？
