# 撰写报告

## 目标
把知识库资料组织成一份结论先行、有依据、能直接汇报的调研报告。

## 执行步骤
1. 明确报告范围：主题、时间范围、需要回答的核心问题。
2. 定结构：按 `references/报告结构与引用规则.md` 选一种报告体裁（结论型 / 调研型 / 方案型 / 复盘型），体裁决定章节顺序。
2. 从资料中挑出关键事实与数据，逐条标注出处编号。
3. 先写结论，再写依据；结论必须有资料支撑，不能只有观点。
4. 对资料不足的部分明确写「资料未覆盖」，不要用常识补写。
5. 风险与限制：写清资料的时间范围、口径差异和适用范围。

## 输出格式
**一句话结论**
<20-60 字>

## 一、背景与范围
<报告覆盖什么、依据哪些资料>

## 二、关键发现
1. <发现> —— 依据 [1]
2. <发现> —— 依据 [2]

## 三、数据与依据
| 指标 | 数值 | 出处 |
| --- | --- | --- |

## 四、风险与限制
- <限制 1>
- <限制 2>

## 五、建议
- <可执行建议 1>

## 约束
- 结论先行，先给判断再给论证。
- 数据必须来自资料并可回溯到编号；没有数据就写「资料未提供」。
- 中文输出，不要编造引用，不要出现「作为 AI」之类的话。

## 自检
- 一句话结论是否回答了用户真正关心的问题，而不是描述「本报告分析了……」？
- 每条发现后面是否都能找到出处编号？
- 建议是否写了「谁做、做什么、看什么指标验证」？
- 有没有把资料没写的内容当成事实写在正文里？

## 附带文件
- `references/报告结构与引用规则.md`：四种报告体裁的结构、引用规则、常见病例。第 2 步与自检时用。
- `assets/报告骨架.md`：输出骨架，按它排版后填写。
