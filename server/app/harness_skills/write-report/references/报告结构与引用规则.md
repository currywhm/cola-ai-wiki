# 报告结构与引用规则

## 一、四种报告体裁（第 2 步先定体裁）

**A. 结论型**（最常用：给领导看、要一个判断）
- 顺序：一句话结论 → 支撑结论的 3 条关键发现 → 依据数据 → 风险与限制 → 建议。
- 适用：用户问「情况怎么样」「该不该做」。

**B. 调研型**（摸清一个对象）
- 顺序：研究问题 → 现状 → 对比 → 差异原因 → 结论。
- 适用：用户问「XX 是什么情况」「A 和 B 有什么区别」。

**C. 方案型**（要在几条路里选一条）
- 顺序：目标 → 可选方案（2-4 个）→ 对比维度打分 → 推荐方案与理由 → 落地步骤与资源。
- 适用：用户问「怎么做」「选哪个」。

**D. 复盘型**（已经发生的事）
- 顺序：目标 vs 实际 → 差异 → 原因（分主观/客观）→ 经验 → 下次改进项。
- 适用：用户问「为什么没做成」「总结一下」。

体裁选错，后面全白写。用户没说时按下面的判据选：要判断用 A，要了解用 B，要决策用 C，要总结用 D。

## 二、引用规则

1. 出处编号必须与资料清单一致，用 `[1]` 形式。
2. 一个句子引用多处，写成 `[1][3]`。
3. 数字型结论必须带出处；没出处的数字不要写。
4. 资料没有的内容，写「资料未提供」或「资料未覆盖」，不要留空也不要猜。
5. 不要编造引用编号——没有对应资料就不写编号。

## 三、常见病例

| 病症 | 表现 | 改法 |
| --- | --- | --- |
| 结论绕圈 | 「本报告对……进行了分析」 | 直接写结论：「目前不建议在 Q4 扩产」 |
| 只有观点没有依据 | 「市场前景广阔」 | 「2025 年国内出货量 320 万台，同比 +12% [2]」 |
| 数据不成对 | 只给增长率不给基数 | 同时给出绝对值与增长率 |
| 建议不可执行 | 「加强管理」 | 「由采购部在 9 月底前把三家供应商的账期统一到 60 天」 |
| 风险写成免责 | 「可能存在一定风险」 | 「若汇率上行 5%，毛利将下降约 1.2 个百分点 [3]」 |

## 四、篇幅控制

- 一句话结论：20-60 字，不要带「本报告」。
- 关键发现：3-5 条，多了说明没收敛。
- 建议：3-5 条，每条一句话，动词开头。
