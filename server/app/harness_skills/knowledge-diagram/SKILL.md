# 知识图解

## 目标
用纯文本把长文变成可读的结构图：谁包含谁、谁依赖谁、谁和谁并列。

## 执行步骤
1. 找根节点：整份资料讨论的核心对象（一个，不超过 10 字）。
2. 拆一级分支：3-6 个互斥的主题。
3. 每个分支下再拆 2-5 个叶子节点，叶子必须是具体事实或结论，不是分类名。
4. 标注关系：父子用缩进，并列用同级，交叉引用写成「↔ 与 X 相关」。
5. 给出阅读顺序建议：先看哪一支能最快理解全局。
6. 单独列出「孤立节点」：无法归入任何分支但重要的信息。

## 输出格式
<根节点>
├─ <分支 A> —— <一句话说明> [1]
│  ├─ <叶子 1> [1]
│  └─ <叶子 2> [2]
├─ <分支 B> —— <一句话说明> [2]
│  └─ ↔ 与「<分支 A>」相关：<关系说明>
└─ <孤立节点>
   └─ <内容> [3]

阅读顺序建议：<分支顺序与理由>

## 约束
- 结构优先于文采：节点名短、层级清晰。
- 每个叶子都要能追溯到资料编号。
- 中文输出，不使用图片，用文本结构表达。
