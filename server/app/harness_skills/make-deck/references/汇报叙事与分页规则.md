# 汇报叙事与分页规则

## 一、四种叙事模式（第 2 步先选模式）

**A. 结论先行**（汇报给上级、时间紧）
- 页序：封面 → 一句话结论 → 3 条支撑 → 数据 → 行动项。
- 特征：听众看前三页就知道要不要继续听。

**B. 问题—方案**（要争取资源）
- 页序：封面 → 问题有多严重（量化）→ 根因 → 方案 → 成本收益 → 需要什么支持 → 时间表。
- 特征：问题页必须带数字，否则争取不到资源。

**C. 时间线**（项目进展、复盘）
- 页序：封面 → 目标 → 里程碑与进度 → 偏差 → 风险 → 下一步。
- 特征：进度用同一口径对比（计划 vs 实际）。

**D. 对比**（选型、竞品）
- 页序：封面 → 对比维度 → 逐维度对比 → 综合结论 → 建议。
- 特征：维度不超过 5 个，超过就分两页。

## 二、每页的四个要素

1. **标题**：结论句，不是名词堆砌。
   - ✅「华东贡献了 75% 的增长」　❌「增长分析」
2. **要点**：3-5 条，每条 ≤ 20 字，能被一眼读完。
3. **版式建议**：结构图 / 柱状图 / 折线图 / 表格 / 纯文字。选版式看数据关系：
   - 比大小 → 柱状；看趋势 → 折线；看占比 → 环形或堆叠；看流程 → 流程条；看取舍 → 矩阵。
4. **讲稿提示**：一句话说明这一页要说服听众什么。

## 三、页数控制

| 场合 | 建议页数 | 每页停留 |
| --- | --- | --- |
| 5 分钟汇报 | 5-8 页 | 30-40 秒 |
| 15 分钟评审 | 10-15 页 | 60 秒 |
| 30 分钟方案 | 15-20 页 | 90 秒 |

超过 20 页就拆成主报告 + 附录。

## 四、常见毛病

| 毛病 | 后果 | 改法 |
| --- | --- | --- |
| 标题是名词 | 听众不知道你要说什么 | 改成结论句 |
| 一页两个观点 | 听众记不住 | 拆成两页 |
| 全是文字页 | 听众看手机 | 至少一半页面用图或表 |
| 数据页没出处 | 被质疑时无法回答 | 右下角标出处编号 |
| 结论页放最后 | 等级高的听众提前走 | 结论提到第 2 页 |
| 「此处可插入图片」 | 等于没做完 | 直接写建议的图类型与内容 |
