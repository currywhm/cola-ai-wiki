# 行业调研

## 目标
把公开信息整理成一份**能支撑决策的调研报告**：每个关键事实都标了来源和可信等级，冲突数据并列呈现，不确定的地方明说不确定。

## 前提与边界
- 本技能必须联网检索。先检索再写，不要凭模型记忆写行业数据；记忆里的数字很可能过期。
- 检索不到就写「公开渠道未检索到」，不要用估算冒充实测数据。
- 涉及市场规模、融资、监管政策、上市公司数据时，优先官方统计、年报／招股书、监管文件。
- 单篇自媒体、营销号、未标日期的文章只能当线索，不能当依据。

## 执行步骤
1. 先写研究问题：用户真正想判断什么？把「了解 XX 行业」翻译成 2-4 个可回答的问题（例如市场规模与增速、主要玩家与份额、盈利模式、进入门槛）。
2. 定检索词：中文关键词、英文关键词、以及关键公司的名称各准备几个，准备多轮检索而不是查一次就写。
3. 检索与抓取：按 `references/调研框架与信源分级.md` 的分级标准记下每条信息的来源、发布时间、口径。
4. 交叉验证：同一个关键数字，至少找两个独立来源。不一致时两个都写，注明差异与可能原因（年份、口径、统计范围）。
5. 结构化整理：按「市场规模与增速 / 产业链与关键环节 / 主要玩家与打法 / 商业模式与盈利点 / 政策与监管 / 风险与不确定性」六块组织。
6. 写结论：3-5 条判断，每条写「判断 → 依据（来源编号）→ 什么情况下这个判断会被推翻」。
7. 给信息来源清单：编号、标题、机构、日期、链接、可信等级。
8. 明确写出本次调研没查到的部分。

## 输出格式
按 `assets/调研报告模板.md` 输出，正文用 [1][2] 标来源。
用户要求交文件时写成 Markdown 文件（形如 `XX行业 调研报告.md`）。

## 自检
- 每个关键数字是否都有来源与日期？
- 是否至少做了两轮不同关键词的检索？
- 冲突数据是否并列而不是二选一？
- 结论是否写了「什么情况下会不成立」？
- 有没有把自媒体观点当事实写？

## 附带文件
- `references/调研框架与信源分级.md`：六块框架的填写要求、四级信源标准、常见数据口径陷阱。第 3、4 步用。
- `assets/调研报告模板.md`：输出骨架，第 8 步之后按它排版。
