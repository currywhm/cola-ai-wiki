# 长文精读

## 目标
把一篇长文读透，产出一份**让没读原文的人也能判断该不该信、该不该采信哪一段**的精读笔记。
精读不是缩写，它要回答三件事：作者想说什么、凭什么这么说、哪里可能不成立。

## 前提与边界
- 只依据用户给到的文本（或本轮检索到的片段）。看不到全文时，在开头注明「基于给定片段，未覆盖部分无法判断」。
- 不要替作者补充论据，也不要把自己的常识当成原文结论。原文没说的，就不要写进「作者观点」。
- 区分事实、推测、观点、情绪。作者带情绪的表述要原样标出，不要中性化。

## 执行步骤
1. 一句话主旨：用不超过 40 字说清「本文主张什么」。写不出来说明还没读懂，回到原文再找。
2. 结构地图：把文章切成 3-7 个部分，每部分一句「这部分在证明什么」。只写功能，不写内容摘要。
3. 关键论断与证据：逐条列出核心论断，每条配「支撑它的事实／数据／案例是哪个」。只有结论没有证据的，标「无证据」。
4. 隐含假设：找出论证成立必须事先成立、但文中没证明的前提，逐条写明「如果这个前提不成立，结论会怎样」。
5. 反例与边界：至少给两条「本文结论不适用」的情形（时间、地区、样本、规模、行业不同）。
6. 与既有资料对照：如果本轮上下文里还有其它资料，指出互相印证、互相冲突的地方；没有就跳过，不要编。
7. 可行动清单：读者看完能做什么，3-5 条，动词开头。
8. 存疑问题：还需要向作者或原始数据确认的问题。

判断问题用 `references/精读提问清单.md` 里的清单逐项过一遍，不要只用眼睛扫。

## 输出格式
按 `assets/精读笔记模板.md` 输出。
用户要求交文件时，写成 Markdown 文件（形如 `《XX》精读笔记.md`），并在回答里给出「值不值得细读」的结论。

## 自检
- 一句话主旨是否能被原文直接支撑，而不是我自己的总结？
- 每条关键论断是否标了证据强弱？
- 隐含假设是否至少找出两条？
- 是否区分了「作者说的」与「我认为的」？
