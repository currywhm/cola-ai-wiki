# 归类与冲突处理

## 一、主题怎么切（第 2 步）

**合格的主题名**
- 是一个名词短语，不是一句话：✅「采购与供应商」、❌「采购流程需要审批」。
- 不超过 12 个字。
- 能装下多条内容；只能装下一条说明切太细。

**切分三条标准**
1. **互斥**：同一条内容只能归属一个主题；归不进去说明主题没切对。
2. **可检索**：读主题名就能猜到里面大概有什么，不要用「其它」「杂项」收尾。
3. **同层次**：不要一个主题是「财务」，另一个是「财务里的报销细节」。

**典型切分维度**（选一种为主，不要混用）
- 按对象：客户 / 产品 / 供应商 / 制度
- 按流程：获取 / 评估 / 采购 / 交付 / 售后
- 按问题：成本 / 合规 / 效率 / 风险

## 二、合并与去重（第 3 步）

同一件事在不同资料里出现时：
1. 先比数字：数字不同先看口径与时间，不要直接相加。
2. 再比范围：一个讲全国、一个讲华东，不能合并成一句。
3. 合并后保留全部出处编号（写作 `[1][3]`），不要只留一个。

**不该合并的情况**
- 一个是事实、一个是观点。
- 时间跨度差得远（一年以上），应分开写并标明年份。

## 三、五类冲突怎么处理（第 6 步）

| 冲突类型 | 判断依据 | 处理方式 |
| --- | --- | --- |
| 口径不同 | 一个是含税、一个是不含税 | 两条都列，标注口径 |
| 时间不同 | 一个是 2024 年，一个是 2026 年 | 按时间列出，注明变化 |
| 范围不同 | 一个是全国，一个是单省 | 两条都列，标明范围 |
| 结论相反 | 两份资料结论相互否定 | 并列列出，写「待确认」，不要选边 |
| 一强一弱 | 一个是官方数据，一个是估算 | 以强信源为主，弱信源作注解 |

## 四、术语统一

- 同一概念只用一个名称。发现「用户/客户」「订单/工单」混用时，选最常见的一个，并在第一条出现时写「（下称××）」。
- 缩写首次出现写全称：如「供应链金融（下称 SCF）」。
- 单位统一：元/万元、天/工作日不要混写。

## 五、反面示例

- ❌ 直接把原文段落搬到「要点」里 → 这是摘抄，不是整理。
- ❌ 主题叫「综合信息」→ 没信息量。
- ❌ 两份资料数据不一致时只写其中一个 → 用户会以为结论确定。
- ❌ 每个主题只写一要点 → 说明主题切得太碎。
