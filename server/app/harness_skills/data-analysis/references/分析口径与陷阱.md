# 分析口径与数据陷阱

## 一、常用指标口径（写清定义再去算）

| 指标 | 定义 | 容易算错的地方 |
| --- | --- | --- |
| 增长率（环比） | （本期-上期）/上期 | 上期为 0 或负数时增长率无意义 |
| 同比 | （本期-去年同期）/去年同期 | 基期被口径调整过，同比就失真 |
| 毛利率 | （收入-成本）/收入 | 成本是否含运费、含税、含人力 |
| 净利率 | 净利润/收入 | 净利润是否含投资收益、政府补助 |
| 客单价 | 收入/订单数 | 分母是订单数还是客户数 |
| 留存率 | 期末仍在的期初用户/期初用户 | 观察窗口（7 日/30 日）必须说明 |
| 人均产出 | 收入/人数 | 人数是期末数还是平均在岗数 |
| 库存周转 | 销货成本/平均库存 | 平均库存用什么方法算 |

## 二、六类数据陷阱（第 4 步逐条对照）

1. **分母悄悄变了**
   现象：比率突然好看，但绝对值没涨。
   核实：把分子分母分别列出来，看是不是分母缩小了。

2. **口径断裂**
   现象：某个时点前后数据「跳变」。
   核实：问这个时点有没有换系统、改统计规则、并入或剥离主体。

3. **幸存者偏差**
   现象：只看现在还活着的样本，得出「这个策略很成功」。
   核实：把已流失、已关停、已退出的样本加回来再看一遍。

4. **辛普森悖论**
   现象：每个分组都在涨，合起来却在跌（或反过来）。
   核实：把总体和分组的变化率并排写出来，看结构占比变了多少。

5. **均值掩盖分布**
   现象：平均交付 12 天，客户却都在投诉。
   核实：同时给出中位数、最大值、以及分布（多少比例超过承诺天数）。

6. **同期不可比**
   现象：拿 28 天的 2 月和 31 天的 3 月直接比总量。
   核实：换成日均、同口径周期，或在结论里明确标注不可比。

## 三、核实问句（写异常原因前问一遍）

1. 这个变化是数据变了，还是记录规则变了？
2. 是不是季节性／周期性（节假日、旺季、结算周期）？
3. 会不会是少数大客户或少数几笔大单造成的（看集中度）？
4. 如果这个异常持续三个月，最该先查哪一环？
5. 有哪些数据缺失，缺失本身是不是一种信号？

## 四、结论写法模板

- 好：「7 月收入 482 万元，环比 +18%，增长集中在华东（贡献 75%），其中 A 客户单笔 96 万元，剔除后增速降到 +6%。」
- 差：「7 月表现良好，增长主要由华东拉动。」

差别在于：有没有数字、有没有剔除干扰项、有没有指出下一步。
